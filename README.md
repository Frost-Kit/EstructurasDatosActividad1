# Gestión de Micros 

Sistema basicon de gestión de flota de micros para Tarija desarrollado en ASP.NET Core.

## 🚀 Tecnologías

* C# / ASP.NET Core MVC
* Bootstrap 5
* HTML5 / CSS3

## 🛠️ Requisitos Previos

* [.NET 10.0 SDK](https://dotnet.microsoft.com/download) (o la versión que uses)
* JetBrain Rider / Visual Studio 2026 / VS Code / Una terminal

## ⚙️ Instalación y Ejecución

1. **Clonar el repositorio:**
 ```bash
 git clone [https://github.com/Frost-Kit/EstructurasDeDatos-Actividad1.git](https://github.com/Frost-Kit/EstructurasDatosActividad1.git)
 cd EstructurasDatosActividad1
 dotnet restore
 dotnet run
 ```
2. **Restaurar dependencias:**
  ```bash
  dotnet restore
  dotnet run
  ```
3. **Ejecutar el proyecto:**
 ```bash
 dotnet run
 ```
